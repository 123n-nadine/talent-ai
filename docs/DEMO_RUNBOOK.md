# دليل تشغيل عرض الديمو (Demo runbook)

كل الأوامر هنا اتجربت فعلًا على السيرفر يوم 2026-10-18 بالترتيب ده: إيقاف كامل ← تشغيل من الصفر ← تأكد ← ترجيع الديمو ← بروفة كاملة بالمتصفح (`tools/demo/rehearsal.py`، صورها في `demo/screens/` وخطواتها في `demo/STEPS.md`) ← ترجيع الديمو تاني. الأوقات المكتوبة هي اللي اتقاست في اليوم ده.

كل الأوامر من مجلد المشروع على السيرفر:

```
cd ~/my-projects/talent-ai
```

## 1. تشغيل كل حاجة من الصفر

الترتيب مهم: المحرك الأول (هو اللي بيعمل الشبكة اللي Frappe بتدخلها)، وبعدين Frappe.

| الخطوة | الأمر | بياخد |
|---|---|---|
| 1. المحرك + النموذج (قاعدة البيانات، Redis، vLLM، الواجهة، 4 عمّال، خدمة التضمين) | `cd talent-engine && make up && cd ..` | 397 ثانية لحد ما الأمر يرجع |
| 2. الواجهة جاهزة | `curl -fs http://127.0.0.1:18000/health` → `{"status":"ok"}` | 397 ثانية من البداية |
| 3. النموذج اللغوي محمّل على الكارت | `docker exec talentai-api-1 python -c "import urllib.request;print(urllib.request.urlopen('http://vllm:8000/v1/models').status)"` → `200` | 408 ثانية من البداية (أطول خطوة: تحميل حوالي 5.6 جيجا من القرص) |
| 4. Frappe (قاعدة البيانات في الذاكرة بتترجع من آخر نسخة احتياطية لوحدها) | `cd dev-frappe && docker compose up -d && cd ..` | 139 ثانية لحد ما الأمر يرجع |
| 5. الموقع بيرد | `curl -fs http://127.0.0.1:18050/api/method/ping` → `{"message":"pong"}` | 565 ثانية من بداية الخطوة 1 |
| 6. موقع الديمو كامل (الشاغر والمتقدمين) | `curl -fs "http://127.0.0.1:18050/api/method/ido_talent_ai.api.job_requirements?job_title=HR-OPN-2026-0001"` → JSON فيه الشروط | مع الخطوة 5: الاستعادة من النسخة الاحتياطية بتتم قبل ما الموقع يبدأ يرد |

**الإجمالي من الصفر لحد الموقع شغال: حوالي 10 دقايق** (565 ثانية في التجربة). ابدئي قبل العرض بنص ساعة عشان تبقي مرتاحة.

تأكد سريع إن كل حاجة شغالة (11 حاوية كلها `Up`، والمحرك والنموذج `healthy`):

```
docker ps --format '{{.Names}} {{.Status}}' | grep talentai
cd talent-engine && make gpu && cd ..        # النموذج بياخد حوالي 9.3 جيجا من الكارت
```

لو `make up` رفض يشتغل برسالة عن الـ builder: ده الحماية بتاعتنا (بنبني بالـ builder الافتراضي بس)؛ الأمر نفسه بيظبطه، ما تستخدميش `docker compose build` مباشرة.

## 2. ترجيع الديمو لأوله (reset)

بيمسح كل التجارب (طلبات جربتيها، قرارات، تغيير أوزان)، ويعمل الموقع من جديد بنفس الشاغرين، ويقدّم الخمسة وعشرين متقدم الوهميين من النموذج العام، ويقيّمهم، ويضيف الطلبين الورقيين وحالات بنك المتقدمين، ويعمل نسخة احتياطية.

```
dev-frappe/reset_demo.sh
```

بياخد حوالي **6 دقيقة** (أغلبها تقييم المتقدمين على النموذج). اعمليه قبل العرض بساعة، ومش محتاج يتعمل تاني إلا لو جربتي حاجة على الديمو. لو عايزة تتأكدي إنه خلص صح:

```
curl -fs "http://127.0.0.1:18050/api/method/ido_talent_ai.api.job_requirements?job_title=HR-OPN-2026-0001" >/dev/null && echo ok
```

وفي المتصفح: الصفحة الرئيسية «التوظيف الذكي» لازم تبيّن شاغرين و27 طلب و0 جاري المعالجة.

## 3. إطفاء كل حاجة بعد العرض (عشان تفضّي كرت الشاشة)

Frappe الأول (عشان بتستخدم شبكة المحرك)، وبعدين المحرك. إيقاف المحرك بيوقّف النموذج وبيرجّع الـ 9.3 جيجا للكارت المشترك.

```
cd dev-frappe && docker compose down && cd ..
cd talent-engine && make down && cd ..
nvidia-smi --query-gpu=memory.used,memory.free --format=csv
```

بياخد حوالي 134 ثانية. البيانات مش بتضيع: أوزان النموذج في volume، وقاعدة بيانات المحرك في volume، وFrappe بتترجع من آخر نسخة احتياطية (بتتاخد مع كل reset وكل ساعتين) أول ما تشتغل تاني. لو عايزة توقّفي النموذج بس وتسيبي الباقي: `cd talent-engine && ./scripts/compose.sh stop vllm` — بس وقتها أي طلب جديد هيبقى «جاري المعالجة» لحد ما ترجّعيه بـ `… start vllm`.

## 4. الروابط من اللابتوب (عبر Tailscale)

السيرفر بيسمع على عنوان Tailscale بس (ومن السيرفر نفسه على 127.0.0.1)، مفيش حاجة مفتوحة على الإنترنت.

| إيه | الرابط |
|---|---|
| المنصة (دخول الموارد البشرية) | `http://100.85.37.127:18050` |
| الصفحة الرئيسية «التوظيف الذكي» | `http://100.85.37.127:18050/desk/ai-recruitment` |
| صفحة الوظائف العامة (زي ما المتقدم بيشوفها، افتحيها في نافذة خاصة) | `http://100.85.37.127:18050/jobs` |
| نموذج التقديم للشاغر | `http://100.85.37.127:18050/ai-apply/new?job_title=HR-OPN-2026-0001` |
| الترتيب | `http://100.85.37.127:18050/desk/ai-ranking?opening=HR-OPN-2026-0001` |
| سجل التدقيق | `http://100.85.37.127:18050/desk/ai-recruitment-audit-log` |
| الكونسول (للمحرك مباشرة، لو حبيتي تورّي المراحل) | `http://100.85.37.127:18000/console` |
| توثيق الواجهة البرمجية | `http://100.85.37.127:18000/docs` |

لازم اللابتوب يكون داخل على نفس شبكة Tailscale. لو الرابط ما فتحش: `tailscale status` على اللابتوب، وعلى السيرفر `docker ps | grep bench` يبقى `Up`.
